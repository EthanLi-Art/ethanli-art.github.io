开篇词 | 从 0 开始搭建一个企业级 Go 应用

“云”是大势所趋，Go 是云时代的语言

  • 云目前是朝着云原生架构的方向演进的，云原生架构中具有统治力（影响力）的项目绝大部分又是用 Go 构建的

学习 Go 项目开发面临的问题

  • 知识盲区
    • 涉及的知识点很多
  • 学不到最佳实践，能力提升有限
  • 不知道如何完整地开发一个 Go 项目
    • 学习知识点零碎，不体系、不全面、不深入
    • 不能把所有知识点有机结合成一个 Go 项目研发体系，真正开发的时候还是一团乱，效率也很低
  • 缺乏一线项目练手，很难检验学习效果
    • 需要学习一线大厂的大型项目构建和研发经验，来检验自己的学习成果
