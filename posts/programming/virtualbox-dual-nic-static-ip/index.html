VirtualBox 配置双网卡并固定 IP
详细讲解如何在 VirtualBox 中配置双网卡（NAT + Host-Only），并为虚拟机设置静态 IP
2020-11-20 19:32 folder programming   label linux   network   virtualbox  

操作概述

虚拟机环境

  • CentOS7


开启双网卡




查看虚拟机的服务器地址

  • 安装虚拟机后需要重启一次才可以看到



设置固定IP

vim /etc/sysconfig/network-scripts/ifcfg-enp0s3

TYPE=Ethernet
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=static # 设置静态IP
DEFROUTE=yes
IPV4_FAILURE_FATAL=no
IPV6INIT=yes
IPV6_AUTOCONF=yes
IPV6_DEFROUTE=yes
IPV6_FAILURE_FATAL=no
IPV6_ADDR_GEN_MODE=stable-privacy
NAME=enp0s3
UUID=9f9e8d3b-a7ad-450a-a6c8-9973fd57ebb7
DEVICE=enp0s3
ONBOOT=yes # 设置yes
IPADDR=192.168.56.110 # 设置固定的ip地址

# 重启网络，使得配置生效
systemctl restart network
